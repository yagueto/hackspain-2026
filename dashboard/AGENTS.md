# Dashboard

- Angular 22 standalone components with signals and lazy-loaded routes. Run commands from `dashboard/`.
- The existing development server is `ng serve` at `http://localhost:4200/`. Preserve that server and port; do not start a second instance unnecessarily.
- Verify with `npm run build`, `npm test -- --watch=false`, and `npm exec --no -- prettier --check "src/**/*.{ts,html,css}"`.
- UI text is Spanish. Keep feature templates and styles separate and use the shared icon component.
- `Home.addresses` is the string-array signal for incoming addresses. `OperationalMap` accepts `addresses` and optional coordinate-bearing `locations`. Known coordinates avoid geocoding requests.
- Leaflet uses its ESM distribution, with types re-exported in `src/leaflet.d.ts`. Tiles are provided by OpenStreetMap and must retain attribution.
- The public Nominatim endpoint is only for this low-volume, single-user demo: one request at a time, at least 1100 ms between starts, no polling or autocomplete, and session caching. Never send confidential addresses. Policy: https://operations.osmfoundation.org/policies/nominatim/ .
- Before multi-user production, move geocoding to a backend with application-wide rate limiting/caching or a suitable hosted/self-managed provider. The endpoint is configurable through the `geocoding-endpoint` meta tag in the served index and the `GEOCODING_ENDPOINT` injection token; replacement endpoints must return Nominatim-compatible results.
- The shared mocks are for isolated tests, not a fallback for API failures. They contain 10 incidents and 25 units; two extra `kind: 'place'` markers are not counted as resources.
- Shared pagination uses `PaginatedList` with `ResizeObserver` and each list's `--page-row-height`; reserve pager space even on a single page to avoid resize loops. The redesigned incident/resource lists scroll. The one-column breakpoint is 800px, with fixed panel heights on mobile.
- The dashboard starts without an incident or resource selection unless a direct link supplies one. Keep the single mode indicator in the topbar; distinguish simulated outbound orders from real inbound Web Calls.
- Unit map locations can have an optional `route` with `status: 'active' | 'completed'`, destination coordinates, an optional destination label and optional intermediate `via` points. Only active routes are queried and drawn. The UI estimates remaining road travel, not historical GPS tracks or live traffic.
- Routing uses an OSRM-compatible endpoint configured by the `routing-endpoint` meta tag / `ROUTING_ENDPOINT` token. The public demo server is for reasonable non-commercial usage only: requests are serialized at 1100 ms intervals, cached for five minutes and never polled. Use a suitable hosted or self-managed backend before production or confidential location data. Policy: https://github.com/Project-OSRM/osrm-backend/wiki/Demo-server .
- Leaflet route rendering is isolated in `resource-route-layer.ts`; route labels use the distance-based midpoint of the road geometry. Keep marker/popup text DOM-created with `textContent`, and respect `prefers-reduced-motion` for incident pulses.
- The dashboard reads `/api/v1/state`, `/api/v1/meta` and SSE `/api/v1/stream` through `Operations`. Preserve the last snapshot and show connection failures/reconnection; HTTP refresh is a 5-second fallback while SSE is unavailable. All three routes must share this source of truth.
- Development uses `proxy.conf.cjs` with `API_PROXY_TARGET` (default `http://127.0.0.1:8001`). For an isolated API on 8002 run `API_PROXY_TARGET=http://127.0.0.1:8002 npm start`. Production must proxy `/api` to FastAPI or supply the `api-base-url` meta tag with suitable backend CORS origins.
- Angular 22 requires Node `^22.22.3 || ^24.15.0 || >=26.0.0`; the system Node 20 is insufficient. Verified with Node 24.20.0: `npm exec --yes --package=node@24.20.0 -- npm run build` and similarly for `npm test -- --watch=false` / Prettier.
- Incoming Web Call reports remain in the incident list even without coordinates. Confirmed reported/operator coordinates and unique backend geocoding candidates can be mapped; geocoded candidates are explicitly labelled approximate. `Home.addresses` includes only already-located incidents, so report addresses never reach frontend public geocoding.
- The agent is autonomous: each proposal renders a "Decisión automática" badge, the agent's `priority_reason`, and a `hold_until` countdown with an "Anular" button backed by `cancelTask`. Only `requires_approval` tasks render confirm/reject actions; incoming reports additionally require location review. Critical decisions never dispatch merely because a question timer expires.
- The operator `API_KEY` lives in a single topbar password input bound to `Operations.operatorKey`, in memory only; never hardcode it, log it, or persist it in browser storage. The topbar also holds the emergency stop (`pause`/`resume`), autonomy state, log toggle and light/dark theme menu.
- Countdowns read the shared `Operations.now` signal (one 1 s interval for the whole app), never a timer per card. Approval carries `expected_updated_at` and location review; changing the report/location invalidates that review. `resume-simulated` is a separate explicit action and is refused by the backend in live mode.
- Preserve `OperationalMap`'s flex host layout. Overriding `app-operational-map` to `display: block` in Home collapses the absolutely positioned Leaflet canvas to zero height. Verify actual canvas dimensions on desktop and mobile for layout changes.
- `/incidencias` is isolated in `features/incidents/` and shares `OperationalMap` with Home. Its list scrolls and the detail map receives only the selected incident (if located) and its associated units.
- Prefer larger operational values over redundant subtitles and captions. Keep semantic labels with `sr-only` or accessible names, the filtered count in the heading, map attribution and error notices.
- `IncidentStore` adapts backend incidents, resources and timeline to the shared UI. `INCIDENT_UPDATES` remains an optional injected adapter for incremental updates; it defaults to `EMPTY`. Keep transport parsing, validation and reconnection in `Operations`.
- `DemoRouteSimulation` remains available for isolated simulated journeys at 10x speed, preserving geometry and progress across maps. Never initialize it with mock units in the live application or infer backend resource arrival from animation. Optional `route.navigation` supplies calculated remaining geometry/time without another routing request.
- Keep incremental marker/polyline updates to avoid restarting incident pulses or recentering the map on every snapshot. Pass stable source locations to the map, not projected arrays on every timer tick.
- `/recursos` reuses the Incidencias layout, resource details, current assignment and prior-intervention links. Resource statuses, capacities, contacts and history come from the backend, not supplemental mock profiles.
- Direct links use `/recursos?recurso=B-03` and `/incidencias?incidencia=INC-001`. `/?incidencia=...` opens the incoming report controls. Preserve query selections while the first snapshot is loading.
- The Home log is a third column at 1200px and above and a modal overlay below that width. Keep it outside `.dashboard-grid` so `SplitPane` manages only the map and operation lists. Preserve keyboard navigation, focus return, drafts and unread-event behavior.
- Questions sort FIFO in the log; incident attention sorts by highest urgency then oldest question. Resolving one question must not clear another pending alert. Question deadlines use real seconds, not route simulation time, and must be enforced by the backend even after navigation or closing the browser.
- Operator answers and their effects must be authenticated, persistent, idempotent by question ID and revalidated against current assignments/status. Ctrl+I is an explicit demo-only operation; never fabricate operational activity during application initialization.
- Install dependencies with the declared npm version as well as a supported Node: `npm exec --yes --package=node@24.20.0 --package=npm@11.19.0 -- npm install --ignore-scripts`. System npm 10 removes the lockfile's native-package `libc` metadata; preserve those platform selectors.
- Initial Leaflet bounds fitting must wait for `requestAnimationFrame` and invalidate the measured size before fitting. Fitting during the first effect can choose zoom 15 while the canvas is still short and leave every marker outside the visible map. Cancel deferred fitting when a user selects a marker or destroys the component.
- Resource rows use a container query as well as the mobile breakpoint, so opening the third-column log does not hide status/detail controls behind a horizontal scroll. Keep actual backend resource status authoritative over any route geometry.
- Snapshot validation covers tasks, reports, timeline entries and coordination questions before publishing them to signals. Invalid SSE messages retain the previous snapshot and restart HTTP recovery; missing metadata must also recover even when SSE stays connected. Delayed question responses must not leak across incident-run resets.
